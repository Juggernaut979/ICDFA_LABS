## How to View and Export

### Viewing Online
- You can view the `.pptx` directly in GitHub using the built-in file previewer.
- Download the latest exported PDF from the [Releases](../../releases) tab for easy offline viewing.

### Editing Locally
Open the slide deck using:
   - Microsoft PowerPoint
   - Google Slides (`File` -> `Import Slides`)
   - LibreOffice Impress

### Exporting to PDF
- In PowerPoint: `File` → `Save As` → `PDF (.pdf)`.
- Or run with LibreOffice CLI:
  ```bash
  libreoffice --headless --convert-to pdf TCP IP Communication in Action Slide.pptm
  ```
